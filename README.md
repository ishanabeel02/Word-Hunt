# Word Hunt Game

Welcome to the **Word Hunt Game**, where you need to search for hidden words on a grid of letters before time runs out! You can choose different difficulty levels, ranging from easy to hard.

## Features:
- Multiple difficulty levels (Easy, Medium, Hard)
- Timer that adds challenge
- Beautiful colored grid display
- Customizable word list
- You have a limited number of attempts to find the words!
  
### How to Play:
1. Choose a difficulty level (Easy, Medium, or Hard)
2. A grid of letters will appear, and you need to find hidden words from the word list.
3. The clock is ticking, so be quick!
4. Try to find as many words as possible before your attempts run out.
